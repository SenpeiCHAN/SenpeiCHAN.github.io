键盘快捷键

不在输入框里时按键即可，用来快速新建内容。

N 新建（按当前页面：临时任务 / 项目 / 章节 / 投稿…）
P 新建项目
S 新建阶段
T或Shift+N 新建任务
Alt+1…6 切换页面
Enter 在「临时任务」输入框回车 = 新增到今日
Esc 关闭弹窗

数据默认保存在当前浏览器；开启云端同步后，记录会通过 HTTPS 保存到你的私有 GitHub Gist，可在不同设备继续。更换设备前建议先同步一次。
